## Proje hakkında

NODE, farklı dil modeli sağlayıcılarıyla tek yerden çalışmayı kolaylaştırmak için geliştirdiğim uygulama. Projeyi zamanla **yerel çalışan yapay zekâ modellerine** odaklayacak şekilde yeniden konumlandırıyorum.

## Teknik mimari

Python/FastAPI tabanlı backend, Ollama entegrasyonu, streaming yanıtlar, model geçişi, API anahtarı yönetimi ve MCP araç entegrasyonu projenin çalışma alanları arasında.

## Hedefim

Kullanıcının kendi bilgisayarında model seçmesini, çalıştırmasını ve araçlarla birleştirmesini kolaylaştırmak. Kurulumu basitleştirmek öncelikli sonraki adımlardan biri.
